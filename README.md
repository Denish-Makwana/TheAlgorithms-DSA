# JavaScript Pattern Programs

This repository contains small JavaScript programs for practising nested loops, recursion, number patterns, star patterns, and spiral matrices. Every program runs independently and prints its result in the terminal.

## Requirements and usage

- Install [Node.js](https://nodejs.org/).
- Open a terminal in this folder.
- Run any example with `node <file-name>`, for example: `node 01-left-aligned-star-triangle.js`.

The variable values inside each file control the size of its output. The code logic has been preserved; only documentation comments and filenames have been improved.
